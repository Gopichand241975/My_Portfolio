## 🛠️ Stack and Tools Used in This Portfolio

This website was developed using lightweight, modern frontend practices and configurations:
- **Build Tool / Local Server:** [Vite](https://vitejs.dev/) (fast, hot-reloading dev environment)
- **Markup:** Semantic HTML5 (designed for SEO accessibility and screen readers)
- **Styling:** Vanilla CSS3 (utilizing CSS custom properties, flexbox/grid layout, glassmorphic backdrop-filters, custom scrollbars, and keyframe animations)
- **Scripting:** Vanilla JavaScript (ES6+ modular logic for typing effects, project filters, mobile navbar toggle, and an interactive terminal console)
- **Typography:** Google Fonts:
  - *Outfit* (for headings and branding titles)
  - *Inter* (for clean, readable body paragraphs)
  - *Fira Code* (for code samples and the interactive terminal shell)
- **Icons:** FontAwesome v6 (vector representations for tech tags, metrics, and navigation symbols)

## 🚀 Running the Project Locally

Follow these quick commands to spin up the local development server:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Setup Instructions
1. Navigate into the portfolio directory:
   ```bash
   cd My_Portfolio
   ```
2. Install the dev dependencies (Vite):
   ```bash
   npm install
   ```
3. Start the Vite hot-reloading dev server:
   ```bash
   npm run dev
   ```
4. Open the displayed local address (usually `http://localhost:5173`) in your web browser.

## 🎨 Interactive Console Terminal (Easter Egg)
The portfolio includes a retro interactive prompt in the Hero section. Click anywhere inside the terminal box and type commands:
- `help` - Show all available inputs.
- `about` - Display summary of education and current AI internship.
- `skills` - Display full skills matrix.
- `projects` - Show breakdown of featured works.
- `certs` - List all professional certifications.
- `contact` - Display direct links, email, and phone numbers.
- `clear` - Clear terminal screen.
